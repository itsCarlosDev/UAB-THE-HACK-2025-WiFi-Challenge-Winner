# Datos de demostración

Los archivos de esta carpeta contienen datos sintéticos creados para que la versión pública del proyecto pueda ejecutarse sin redistribuir el dataset utilizado durante UAB THE HACK! 2025.

Incluye:

```text
rookie_filtered_aps.json
rookie_filtered_clients.json
```

La demo contiene:

- 3 AP ficticios: `AP-DEMO-01`, `AP-DEMO-02` y `AP-DEMO-03`;
- 15 observaciones sintéticas;
- una única fecha de demostración;
- 4 franjas horarias.

Los identificadores, métricas, zonas y coordenadas de esta carpeta son de demostración.

No deben interpretarse como muestras, mediciones ni ubicaciones de la infraestructura real de la Universitat Autònoma de Barcelona.
